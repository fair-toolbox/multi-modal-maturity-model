# Examples

This directory contains example configuration for the Multi-Modal Maturity Model:

- [`config.example.yaml`](config.example.yaml) — example custom weights file, usable via `--weights` (CLI) or `weights_path` (Python)

The default configuration files (`weights.yaml`, `metrics.yaml`, `patterns.yaml`) ship with the package in `src/mmmm/config/default/`.

See the [configuration documentation](https://fair-toolbox.github.io/multi-modal-maturity-model/configuration/) for a full reference.
